# Content I18n Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Localize all user-facing site copy (homepage, content sheets, aria labels, locale switcher) through Paraglide/inlang for `it` and `en`.

**Architecture:** Paraglide message catalogs are the single source of truth for strings. Content sheet builders call message functions at render time and attach existing media assets, returning the same `ContentSheet` shape. Homepage prose uses Paraglide messages for every visible fragment while keeping CSS class markup in the page. A visible locale switcher uses Paraglide `localizeHref` / `getLocale`.

**Tech Stack:** SvelteKit, Svelte 5, Paraglide JS 2 (`@inlang/paraglide-js`), Vitest, Bun

## Global Constraints

- Locales: `it` (base), `en` — do not add others
- Message format: flat keys in `messages/{locale}.json` (Paraglide-recommended; use `m.key()` not nested object access)
- Call message functions during render / builder invocation — never bake strings at module top-level as constants
- Keep Italian CV PDF URL `/curriculum-vitae.pdf` for both locales; label must note Italian availability
- Translate item names as well as descriptions
- Preserve existing `ContentSheet` / `ContentItem` / `MediaItem` types and components
- Package manager: `bun`
- Do not rework overall page layout beyond i18n + switcher

```svelte
<script lang="ts">
	import type { Pathname } from '$app/types';
	import { resolve } from '$app/paths';
	import { page } from '$app/state';
	import * as m from '$lib/paraglide/messages';
	import { getLocale, locales, localizeHref } from '$lib/paraglide/runtime';

	const flags: Record<string, string> = {
		it: '🇮🇹',
		en: '🇬🇧'
	};

			href={resolve(localizeHref(page.url.pathname, { locale }) as Pathname)}
			class="locale-link"
			class:current={locale === getLocale()}
			hreflang={locale}
			aria-current={locale === getLocale() ? 'page' : undefined}
		>
			{locale}
			<span aria-hidden="true">{flags[locale] ?? ''}</span>
		</a>
	{/each}
</nav>

		@apply text-stone-700 no-underline;

		text-underline-offset: 3px;

		@apply underline decoration-stone-400;
	}

		@apply underline decoration-stone-900;
```
